关于 IP Lens

IP Lens 汇总免费 IP 基础信息与常用检测入口。IP 地址数据由 IPinfo 提供。

当前 IP 是访问对应检测服务时看到的出口。开启代理分流时，其他网站看到的出口可能不同。

免费基础查询不提供 VPN、住宅身份和欺诈风险结论。没有数据的字段显示“未提供”，不会推断为安全。

Scamalytics 在原位置提供带入查询 IP 的风险评估入口。具体分数与详细信息请在原站查看。

页面在本机保存检测源偏好，不保存查询历史。使用其他检测站时，查询 IP 会发送至对应服务。
